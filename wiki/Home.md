# ToadTools — плагины для Autodesk Revit

**ToadTools** — набор инструментов для Autodesk Revit, который автоматизирует рутину проектировщиков и BIM-специалистов: проверку и выгрузку моделей, заполнение параметров, марки, кабельные лотки, теплопотери, армирование и многое другое.

Все инструменты — на отдельной вкладке **ToadTools**, сгруппированы по разделам. Выберите нужный в таблице ниже или в меню справа.

## Инструменты

### 🟦 BIM
| Инструмент | Что делает |
|---|---|
| [ParamChecker](ParamChecker) | Проверяет заполнение параметров (LOI) в моделях с Revit Server и выгружает отчёт в Excel |
| [ToadExporter](ToadExporter) | Пакетно выгружает модели с Revit Server или из папки в RVT и NWC |
| [Создание рабочих наборов](WorkingSet) | Создаёт стандартные рабочие наборы раздела по Excel-таблице |
| [Проверка рабочих наборов](WorksetCheck) | Проверяет распределение элементов по рабочим наборам и исправляет найденное |
| [Копирование элементов](ModelTransplanter) | Переносит содержимое одной модели в другую с учётом координат |
| [Общие → необщие](ChangeSharedFamilies) | Делает вложенные общие семейства необщими (в редакторе семейства) |

## Общее для всех плагинов

- **Окно прогресса.** Долгие команды показывают этап, полосу и время работы. Кнопка **«Прервать»** останавливает команду и откатывает изменения в модели.
- **Отмена одним Ctrl+Z.** Команды, которые меняют модель, идут одной операцией — если результат не понравился, нажмите **Ctrl+Z**.
- **Тема окна.** Переключатель светлой и тёмной темы — внизу окон; выбор запоминается.
- **Справка на ленте.** Наведите курсор на любую кнопку ToadTools и нажмите **F1** — откроется её страница в этой вики.

## Установка

Готовый установщик (MSI) распространяется в виде релиза. После установки плагины появляются на ленте Revit во вкладке **ToadTools** — больше ничего делать не нужно.

> [!TIP]
> Часть инструментов использует общие файлы с сетевого диска компании `Y:` (семейства, таблицы, ФОП). Если вы работаете вне корпоративной сети, такие файлы нужно получить отдельно — они лежат в папке assets.

## Обратная связь
