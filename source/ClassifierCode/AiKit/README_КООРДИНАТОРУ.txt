Рабочая папка объекта для сборки профиля классификатора с ИИ-агентом.

1. Положите сюда таблицу кодов заказчика (.xlsx).
2. Откройте в этой папке Claude Code (или Codex) и напишите:
     Собери профиль классификатора для объекта по CLAUDE.md. Таблица кодов — <имя файла>.xlsx.
   Агент сам прочитает инструкцию (CLAUDE.md / AGENTS.md), проверит профиль проверялкой kit\check\check.exe
   и напишет отчёт.
3. Прочитайте REVIEW.md: итог, коды с частыми наименованиями, спорное, вопросы. Ответьте агенту на вопросы и
   замечания — он поправит профиль и обновит отчёт.
4. ОШИБКИ_В_МОДЕЛЯХ.tsv — элементы, которые проектировщикам нужно поправить в моделях (не та система, не тот
   рабочий набор). Профиль под эти ошибки не подгоняется.
5. Готовый профиль — profile.classifier.json. Проверьте его в Revit: «Код по классификатору» → импорт профиля →
   «Настроить…» → вкладка «Проверка». Затем положите файл в общую папку профилей — проектировщики увидят его
   в окне запуска.

Повторная выгрузка из Revit обновляет exports\ и kit\, но не трогает work\, profile.classifier.json и REVIEW.md:
после выгрузки дополненных моделей попросите агента прогнать профиль заново.

Что где:
  exports\           выгрузки моделей и журнал выгрузки (_журнал.txt)
  kit\               инструкции, профиль-основа и проверялка — не менять
  work\              рабочие файлы агента
