# 3.1.1

**Код по классификатору**
- Набор обрабатываемых категорий приведён к утверждённому списку
- Обрабатываются только элементы категорий из списка (раньше — любые элементы с параметром кода)
- Если параметры классификатора уже есть в проекте, но привязаны не ко всем категориям, недостающие категории добавляются к привязке автоматически

**ParamChecker**
- Исправлено: отчеты сохранялись на рабочий стол, а не в папку, выбранную в настройках
- Папка для отчетов теперь запоминается между запусками
- Исправлено падение при обновлении общего отчета, если путь к нему еще не задан в настройках

**Исправления в других плагинах**
- Копирование элементов: в поле пути к логу отображалось имя класса вместо пути к файлу
- Создание рабочих наборов: окно больше не падает при пустом пути к Excel-файлу, а без выбранного файла показывается предупреждение вместо ложного сообщения об успехе
- Замена общих семейств, Разместить крышки, Создание пространств: исправлены падения на параметрах и типах без имени

**Сборка**
- Устранены все предупреждения компиляции во всех конфигурациях (Revit 2020–2027)
- Устаревшие API Revit заменены на актуальные для версий 2024+
