# ToadExporter

**ToadExporter** выгружает отмеченные модели с Revit Server или из папки на диске в RVT, NWC или оба формата сразу.
Модели обрабатываются по одной в текущем сеансе Revit, исходные файлы при этом не изменяются.

## Источник моделей

Переключатель вверху окна выбирает источник: **Revit Server** или **Папка**.
Один запуск работает только с одним источником.

- **Revit Server.** Список серверов берётся из `RSN.ini` той же версии, что и запущенный Revit (`C:\ProgramData\Autodesk\Revit Server <год>\Config\RSN.ini`). Имя сервера можно вписать вручную. Версия Revit Server совпадает с версией Revit.
- **Папка.** Дерево показывает подпапки и модели `.rvt`. Папки `*_backup`, резервные копии вида `имя.0001.rvt` и папки без моделей не показываются.

Кнопка «Обновить» перечитывает источник.

## Дерево моделей

У каждой модели две галочки: **RVT** и **NWC**.
Галочка на папке отмечает всё её содержимое, включая вложенные папки; содержимое сервера при этом догружается целиком.
Если внутри папки отмечена только часть моделей, галочка папки показывает частичное состояние; щелчок по ней отмечает всё.

Ссылки «Все RVT», «Все NWC» и «Снять все» действуют на всё дерево.
Поиск фильтрует модели по части имени среди уже загруженных папок.
Под деревом показано, сколько моделей отмечено в каждом формате.

## Настройки

Все настройки сохраняются между запусками.

### Конфигурации

Кнопка «Сохранить конфигурацию» записывает в файл `.json` все настройки выгрузки и отмеченные модели с их форматами.
«Загрузить конфигурацию» применяет настройки из файла, перечитывает источник и отмечает сохранённые модели; папки с ними раскрываются.
Отметки, сделанные до загрузки, снимаются.
Если какой-то модели из конфигурации в источнике больше нет, окно выводит их список.
Тема и свёрнутые блоки настроек в конфигурацию не входят.

### Выгрузка

RVT и NWC сохраняются в одну папку результатов под именем исходной модели.
Существующие файлы перезаписываются.
В эту же папку записывается журнал `ToadExporter_<дата>_<время>.log`.

### Открытие

| Настройка | Действие |
|---|---|
| Не загружать связи | Модель копируется во временную папку `%TEMP%\ToadExporter`, связям RVT в копии ставится «не загружать». Открываются все рабочие наборы, связи не загружаются. Неудалённые связи сохраняются в RVT выгруженными, в NWC связей нет. |
| Проверка (Audit) | Revit проверяет и исправляет модель при открытии. Открытие идёт заметно дольше. |
| Не открывать рабочие наборы, содержащие | Рабочие наборы, в имени которых есть указанный текст, остаются закрытыми. Элементы закрытых наборов не попадают в NWC. |

Модели совместной работы открываются с отсоединением и сохранением рабочих наборов.

### RVT — обработка перед сохранением

Перед сохранением выбранные элементы удаляются из открытой копии: связи RVT и IFC, импорт и связи CAD, облака точек.
«Очистить неиспользуемое» доступно с Revit 2024.
«Сжать файл» уменьшает размер сохраняемого файла.

Модель совместной работы сохраняется в папку результатов как локальная копия с рабочими наборами — так же, как её создаёт `RevitServerTool createLocalRVT`.
Файл хранилища этой копии остаётся во временной папке и удаляется после выгрузки, поэтому Revit при открытии копии сообщает, что файл хранилища недоступен.
Модель без совместной работы сохраняется обычным файлом.

### NWC

В NWC выгружается только 3D-вид с именем из настройки «Имя 3D-вида для экспорта».
Если такого вида в модели нет, NWC для неё пропускается, причина записывается в журнал, RVT сохраняется как обычно.
Остальные параметры соответствуют параметрам экспорта Navisworks в Revit и сгруппированы в три сворачиваемых блока.

NWC выгружается до обработки RVT: удаление связей и CAD на NWC не влияет.

Если Navisworks Exporter для Revit не установлен, вверху окна выводится предупреждение, а колонка NWC и настройки NWC неактивны.

## Запуск

Перед запуском окно проверяет, что отмечены модели, задана папка результатов и она не совпадает с папкой исходной модели.
Если среди отмеченных есть одноимённые модели из разных папок, окно предлагает продолжить (останется последняя) или отменить запуск.

Во время выгрузки окно прогресса показывает текущую модель и этап работы.

- **Пропустить модель** прерывает работу с текущей моделью, закрывает её без сохранения и переходит к следующей.
- **Прервать** останавливает выгрузку после закрытия текущей модели.

Ошибка в одной модели не останавливает выгрузку: модель отмечается в журнале с текстом ошибки.
В конце выводится итог: сколько моделей выгружено, пропущено и завершилось с ошибкой; кнопка «Да» открывает журнал.
Кнопка «Открыть последний журнал» открывает последний журнал из папки результатов.
